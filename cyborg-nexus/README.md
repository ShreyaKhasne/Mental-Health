# CYBORG // NEXUS — TechFest

A responsive, interactive 3D cyborg landing page built for the TechFest web-development challenge.

## Run locally

```bash
cd cyborg-nexus
npm install
npm run dev
```

Open: **http://localhost:5173**

The main experience is in `index.html`; it uses Three.js for the live 3D robot, cursor interaction, animated UI, responsive navigation, modules, timeline, simulation modal and contact form.
